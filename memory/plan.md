# 书籍大纲书签重做计划

目标：为《Python语言程序设计基础 第三版 (嵩天, 黄天羽, 杨雅婷).pdf》重做层级规范、跳转精准的完整大纲书签。

1. 结构与页码映射分析：
   - 原始 PDF 共有 416 页，原有目录为扫描工具生成的无意义时间戳标签（425 条）。
   - 正文起始页为第 25 页（正文印刷页码第 5 页），全书正文页码映射关系严格为：PDF 页码 = 纸质印刷页码 + 20。
   - 前置部分（封面、扉页、版权页、增值服务、三版前言、学习导读、三维索引、目录）及各篇章人物传记导语均已精准定位。

2. 书签构建：
   - 涵盖“前置内容、第一部分、第二部分、第三部分、附录与后记”共 5 大板块。
   - 包含 10 个正文章节、全部二级/三级小节、18 个编程实例、重要计算方法，以及全书 13 位著名计算机科学家传记导语。
   - 共计 311 条书签，层级深度 1~4 级。

3. 写入与验证：
   - 使用 PyMuPDF (`fitz`) 的 `set_toc` 写入新书签并保存。
   - 校验新书签数量、层级树结构、单调性与跳转页有效性。
   - 更新 docs/CHANGELOG.md 与会话归档。
