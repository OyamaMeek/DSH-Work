# 验证标准

- 书签覆盖完整性：
  - 上册：包含前置部分、第 1~11 章所有章节小节与细分知识点、附录I、附录II、习题答案、索引、简史及封底，共计 177 条书签。
  - 下册：包含前置部分、第 12~23 章所有章节小节与细分知识点、习题答案、索引及封底，共计 158 条书签。
- 页码跳转准确性：
  - 上册正文页码映射严格满足：PDF 页码 = 纸质印刷页码 + 11。
  - 下册正文页码映射严格满足：PDF 页码 = 纸质印刷页码 + 8。
  - 多点抽样 OCR 核查所有关键章节与小节，标题与内容 100% 匹配。
- 书签树规范性：
  - 章节为 1 级，小节（§）为 2 级，子小节（一、二……）为 3 级，前置与后记条目层次合理。
  - 全书书签页码单调递增且均在合法有效页码范围内。
- 文件完整性：
  - PDF 结构完整无损，阅读器可正常解析与展开完整层级大纲。
