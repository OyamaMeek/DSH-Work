## 核心主旨

Codex 从单纯的代码聊天框跃升为全能生产力智能体的关键，在于灵活插拔的 Skill 与 Plugin 体系。本指南按岗位维度与高频办公需求，盘点通用必装三件套以及面向设计、音视频、电商运营及日常办公的专属神器。

---

## 通用基石必装三件套

| 核心组件 | 功能机制 | 业务解决价值 |
| :--- | :--- | :--- |
| **1. BrowserSkill** | 开箱即用的浏览器直接接管与控制技能。 | 自主打开网页、搜索权威资料、填表下载，实现网络信息采集与表单自动化。 |
| **2. Computer Use** | 从聊天窗口突破到全系统操控的关键能力。 | 视觉识别屏幕画面、敲击键盘、点击鼠标，直接调用 Xcode、终端及本地桌面软件。 |
| **3. Analytics** | OpenAI 官方专属角色插件，连接多平台数据。 | 自动跨表读取、图表绘制、撰写数据复盘分析报告，赋能业务洞察。 |

### 1. 产品与 UI/UX 设计岗
- **UIUX Pro Max**：
  - GitHub 爆火的开源专业设计 Skill；
  - 内置数百套配色规范、字体搭配组合、图表类型指南与标准 UX 交互规范，显著提升 AI 生成界面的专业质感。

### 2. 视频创作与剪辑编导岗
- **剪映自动化 Skill**：用代码控制时间线剪辑、转场与字幕排版；
- **OmniVoice（小米开源语音模型）**：
  - 支持 600+ 种语言极速零样本克隆；
  - 推理速度极快（40 倍速于实时），支持细粒度语气控制（低语、方言、情绪）；
- **HeyGen 数字人 + Video Use**：从分镜脚本生成、数字人出镜口播到工程合成全流程跑通。

### 3. 电商与业务运营岗
- **Record & Replay**：
  - 核心逻辑：“演示一次，即刻自动化”；
  - 录制商品上架、库存盘点、报活动、导报表的繁琐鼠标键盘操作，转化为可反复执行的自动化技能。

### 4. 职场日常白领必备
- **Office CLI（`thomasfuk/officecli`）**：
  - 一键批量产出结构化 Excel 表格、排版规范的 Word 文档与高质量 PPT 演示文稿，摆脱手动调整格式的重复劳动。
