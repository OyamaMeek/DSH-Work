## 还原出来的关键结论

授权不是简单的本地开关：

```objc
// 0x3797f4，15 处调用点，全部功能开关的唯一入口
BOOL SJJCapabilityAllowed(NSDictionary *claims, NSString *capability) {
    if (capability.length == 0) return NO;
    if (![claims[@"authorized"] boolValue]) return NO;
    if ([claims[@"blocked"] boolValue]) return NO;
    id list = claims[@"capabilities"];
    if (![list isKindOfClass:NSArray.class]) list = @[];
    return [list containsObject:capability];
}
```

策略来自 `http://119.45.40.202/api/package_policy.php`（IP 是四个立即数 119/45/40/202 拼的），
返回 JSON 的 `authorized` / `blocked` / `capabilities`；
本地还有 `SJJPKG1` 三槽门禁包，用 RSA PKCS#1 v1.5 SHA-256 校验策略签名，封装在 `0x38d36c`。
SVIP 判定 `0x157bc8` 走的就是同一个能力函数，能力键是 `svip`。

## 可信度

- 高：类结构、方法签名、选择子、字符串、调用关系、指令地址。
- 中：伪代码控制流真实，变量语义靠推断；混淆器的不透明谓词（`eor x16, x30, x30, lsl #1; tbz; brk #0xc471`）原样保留。
- 低：局部变量名、被内联函数边界、Category 归属。

想继续推进的话，可以挑一个模块（比如 SJJMediaManager 的转码链或 AWECAAIReplyService 的自动回复策略）做逐行语义重写，产出可编译的等价实现。
