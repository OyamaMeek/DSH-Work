## 骨架是什么样

每个方法都标注了原始地址，方法体按返回类型返回零值，属性自动 `@synthesize`：

```objc
// 0x00011ebc
-(void)setCompletionBlock:(id)forDownloadID:(id)completionBlock { }

// 0x000120bc
-(id)downloadIDForFileURL:(id)fileURL { return NULL; }
```

对照 `reconstructed/pseudocode/SJJMediaManager.m` 同地址的伪代码就能往里填逻辑。

## 期间修掉的几个真问题

- 多参数方法声明：之前生成成 `URLSession:(id)a:(id)b:(id)c`，正确写法是 label 之间用空格不用冒号，否则 selector 变成 `URLSession:::`。
- 类型编码：对象类型要补 `*`，`B`/`q`/`Q` 要还原成 BOOL/long long/unsigned long long，C 数组 ivar 的 `[15]` 要放到变量名后。
- weak 属性与 ivar 的 `__weak` 必须一致，否则编译直接报错。
- 跨类 ivar 类型需要 `@class` 前向声明，包含抖音侧未在 dylib 里声明的 `AWE*` 类型。
- 匿名结构体参数（编码 `{?...}`）的方法跳过，全样本只有 2 个。

## 边界

- 6 个 `AWE*` 类只保留头文件、不生成 `@implementation`，避免和抖音同名类冲突；接管它们要用 `SJJHookInstaller`。
- 实现全是空壳，装上去只会打印 `[sjj] siwenjiajia 28.55 reconstructed-skeleton`。要功能就按 `reconstructed/walkthrough` 的五个模块顺序填。
- 授权逻辑没有移植：原 dylib 的判定在 `0x3797f4`，绕过方式还是之前那个 4 字节补丁。

## 构建命令

```bash
export THEOS=/opt/theos
ln -sfn "$(xcrun --sdk iphoneos --show-sdk-path)" "$THEOS/sdks/iPhoneOS18.5.sdk"
cd sjj-theos && make package
```
