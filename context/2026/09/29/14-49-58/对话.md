# 对话

## 用户

任务目标：
对《计算机网络（第8版）（谢希仁）.pdf》进行处理，使其文字可选中复制、压缩文件体积，并添加大纲书签。

核心硬性约束：
- 严禁重新排版：绝对不要尝试提取图文重构版面或用代码从头生成文档，必须基于原 PDF 页面进行底层修改。
- 保留原貌：页面原版布局与插图不变，文字部分通过在底图上叠加透明文本层（双层可搜索 PDF）实现可选中、可复制与检索。

执行步骤：
- 读取目录页文本，整理标准大纲树结构，校准正文实际页码与 PDF 物理页码的偏移，并使用 PyMuPDF `doc.set_toc()` 写入书签。
- 优先检查 `ocrmypdf`；不可用时，通过 Python 处理底图压缩与坐标 OCR 文本嵌入。

## 助手

已基于原始 PDF 页面完成透明 OCR 文本层、大纲书签和压缩处理，并完成结构与检索验证。
