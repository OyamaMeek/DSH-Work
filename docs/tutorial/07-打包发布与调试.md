# 07 打包发布与调试

## 1. 打包

```bash
make clean package            # rootful（/Library/MobileSubstrate）
THEOS_PACKAGE_SCHEME=rootless make package   # rootless（/var/jb）
```

产物是 `packages/<包名>_<版本>_iphoneos-arm.deb`。看内容：

```bash
ar t packages/*.deb                    # debian-binary / control.tar.* / data.tar.*
mkdir /tmp/x && cd /tmp/x && ar x /path/to.deb && tar tf data.tar.lzma
```

标准结构：

```
Library/MobileSubstrate/DynamicLibraries/siwenjiajia.dylib
Library/MobileSubstrate/DynamicLibraries/siwenjiajia.plist
```

rootless 会自动加上 `/var/jb` 前缀。

## 2. 签名

| 场景 | 做法 |
| --- | --- |
| 越狱设备 | Theos 自动用 ldid 签，不用管 |
| TrollStore / 侧载 | 注入器会重签整个 ipa；单独换 dylib 时手动 `ldid -S 文件` |
| arm64e 设备 | 必须重签，否则指针认证会拒绝加载 |

检查签名：

```bash
codesign -dvvv siwenjiajia.dylib     # 看 CodeDirectory / flags
ldid -h siwenjiajia.dylib            # 看 entitlements
```

## 3. 安装

```bash
# 越狱 + SSH
make install

# 手动
scp packages/*.deb root@<设备IP>:/var/root/
ssh root@<设备IP> "dpkg -i /var/root/*.deb && killall -9 Aweme"
```

TrollStore 方案不用 deb 包，直接把 dylib 喂给 TrollFools。

## 4. 日志

```bash
idevicesyslog | grep '\[sjj\]'                 # 全设备日志
ssh root@<IP> "tail -f /var/log/syslog | grep sjj"
log stream --predicate 'process == "Aweme"'      # macOS 侧（需要设备信任）
```

日志纪律：

- 统一前缀 `[sjj]`，方便过滤；
- 关键路径打一行就够，别在循环里打；
- 发布版用 `#ifdef DEBUG` 包起来。

## 5. 崩溃排查

崩溃文件在设备的 `/var/mobile/Library/Logs/CrashReporter/`，或 Xcode → Devices → View Device Logs。

符号化：

```bash
atos -o siwenjiajia.dylib -arch arm64e -l 0x<加载基址> 0x<崩溃地址>
```

加载基址从崩溃日志的 `Binary Images` 段拿。Theos 构建默认带 debug 符号
（`+debug` 后缀），发布前去掉：`make package FINALPACKAGE=1`。

三类高频崩溃：

| 崩溃 | 原因 |
| --- | --- |
| `EXC_BAD_ACCESS` 在 `objc_msgSend` | 对已释放对象发消息，或 hook 签名错导致寄存器错位 |
| `EXC_CRASH (SIGABRT)` | 数组越界、字典插入 nil、断言失败 |
| 启动即崩 | `%ctor` 里访问了尚未初始化的类，或链接了不存在的符号 |

## 6. 版本适配

宿主每次更新都可能改类名、改方法名、改调用时机。三条纪律：

1. **所有 hook 都要能失败**：类或方法找不到就跳过，绝不崩。
2. **加版本探测**：启动时把关键类/方法的存在性打一条日志，出问题一眼看出是哪个没了。
3. **方法签名变更要早发现**：类型编码变了（比如 `NSInteger` 变 `long long`）时，
   编译期看不出来，运行时才会错位。可以在安装钩子前用 `method_getTypeEncoding` 比对。

```objc
const char *enc = method_getTypeEncoding(method);
if (strcmp(enc, "v24@0:8@16") != 0) {
    NSLog(@"[sjj] signature changed: %s", enc);
    return NO;
}
```

## 7. 发布

- 建一个 apt 源（Sileo/Zebra）：`Packages` 索引 + `*.deb` 放同一目录即可。
- `control` 里写清 `Depends: mobilesubstrate`、`Architecture: iphoneos-arm`。
- rootless 版本要把 `Architecture` 改成 `iphoneos-arm64`。
- 更新检查可以放在插件里：拉一个 JSON 比对版本号，提示用户去源里更新。

## 8. 本工程的对应文件

- `sjj-theos/Makefile`：每个变量的作用都写了注释
- `sjj-theos/control`、`siwenjiajia.plist`：deb 元信息与注入过滤
- `sjj-theos/packages/`：实际构建产物（406 KB，arm64 + arm64e）
