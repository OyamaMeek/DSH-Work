# 04 设置面板与偏好

插件没有设置面板就是一堆写死的开关。这一篇讲怎么把面板塞进宿主 App，以及怎么存配置。

## 1. 找入口：什么时候插入 UI

三种常用时机，按侵入程度排序：

| 方式 | 做法 | 适用 |
| --- | --- | --- |
| 挂到已有页面 | hook `viewDidAppear:`，往 `self.view` 上 addSubview | 局部按钮 |
| 挂到窗口 | hook `UIWindow` 的 `makeKeyAndVisible`，加悬浮球 | 全局入口 |
| 手势触发 | 给窗口加长按/双击手势，弹出面板 | 隐蔽入口 |

项目里常见的是“悬浮球 + 长按”：

```objc
%hook UIWindow
- (void)makeKeyAndVisible {
    %orig;
    static dispatch_once_t once;
    dispatch_once(&once, ^{
        UILongPressGestureRecognizer *g =
            [[UILongPressGestureRecognizer alloc] initWithTarget:self action:@selector(sjj_openPanel:)];
        g.minimumPressDuration = 1.5;
        [self addGestureRecognizer:g];
    });
}
- (void)sjj_openPanel:(UILongPressGestureRecognizer *)g {
    if (g.state == UIGestureRecognizerStateBegan) { /* 弹面板 */ }
}
%end
```

注意：`sjj_openPanel:` 是**新增**方法，要在 `%hook` 外加
`%new`（Logos）或 `class_addMethod`（runtime）才存在。

## 2. 面板结构

一个能扩展的面板通常是两级：

```
主面板（列表）
├── 视频
│   ├── 下载画质          → 二级页
│   └── 进度条样式        → 二级页
├── 交互
└── 关于
```

本项目把这套结构做成了一个通用方法：

```objc
-(void)sjjPresentSecondarySettingsPageWithTitle:(NSString *)title
                                       subtitle:(NSString *)subtitle
                                        tintTag:(NSInteger)tag
                                        builder:(void (^)(UIView *container))builder;
```

调用方只写 builder，页面承载、返回按钮、动画、原地刷新都由主面板处理：

```objc
[self sjjPresentSecondarySettingsPageWithTitle:@"下载" subtitle:nil tintTag:1001
                                       builder:^(UIView *container) {
    UISwitch *sw = [[UISwitch alloc] init];
    sw.on = [SJJPrefs boolForKey:@"sjj_download_enabled_v1"];
    [sw addTarget:self action:@selector(sjjSwitchChanged:) forControlEvents:UIControlEventValueChanged];
    [container addSubview:sw];
}];
```

这套写法的关键点：

- **页面只创建一次**，之后用 `sjjRefreshSecondarySettingsPageContentInPlace` 原地重建内容，
  避免反复 push 导致导航栈膨胀。
- 每个二级页带 `tintTag`，用来定位“当前在哪一页”，恢复现场时用。

## 3. 偏好存储

`NSUserDefaults` 就够用，但要有纪律：

```objc
static NSString *const kSJJDownloadEnabled = @"sjj_download_enabled_v1";

BOOL on = [[NSUserDefaults standardUserDefaults] boolForKey:kSJJDownloadEnabled];
[[NSUserDefaults standardUserDefaults] setBool:on forKey:kSJJDownloadEnabled];
```

三条规则：

1. **统一前缀**：`sjj_`。避免和宿主的键撞车（本项目里 661 个键，全部带前缀）。
2. **带版本后缀**：`_v1`、`_v2`。默认值语义变了就换版本号，老用户的残留值不会污染新逻辑。
3. **集中常量**：把所有键写进一个头文件，避免手打字符串打错。

需要“不进 iCloud 备份”的敏感配置（比如 API Key）时用 Keychain：

```objc
NSMutableDictionary *q = [@{(__bridge id)kSecClass: (__bridge id)kSecClassGenericPassword,
                            (__bridge id)kSecAttrService: @"sjj.qwen"} mutableCopy];
q[(__bridge id)kSecValueData] = [key dataUsingEncoding:NSUTF8StringEncoding];
SecItemDelete((__bridge CFDictionaryRef)q);
SecItemAdd((__bridge CFDictionaryRef)q, NULL);
```

## 4. 跨进程通知

tweak 跑在 App 进程里，但你可能还有别的组件（小组件、SpringBoard 插件）。
用 Darwin 通知跨进程广播配置变更：

```objc
// 发
CFNotificationCenterPostNotification(CFNotificationCenterGetDarwinNotifyCenter(),
    CFSTR("com.you.sjj.prefs.changed"), NULL, NULL, true);

// 收
CFNotificationCenterAddObserver(CFNotificationCenterGetDarwinNotifyCenter(), NULL,
    (CFNotificationCallback)SJJPrefsChanged, CFSTR("com.you.sjj.prefs.changed"), NULL,
    CFNotificationSuspensionBehaviorDeliverImmediately);
```

## 5. 深色模式与材质

- 颜色用 `UIColor` 的动态色（`colorWithDynamicProvider:`），不要写死 RGB。
- 毛玻璃用 `UIVisualEffectView` + `UIBlurEffectStyleSystemMaterial`，跟随系统。
- 面板出现时给 `view.layer.cornerCurve = kCACornerCurveContinuous`，圆角观感才对。
