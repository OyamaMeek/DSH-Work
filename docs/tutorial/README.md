## 先看结论

一个能用的插件，工作量大头不在写代码，而在两件事：

1. **定位**：抖音的类名、方法名、调用时机，全都得自己找。混淆过的二进制更麻烦，
   本项目的做法是解析 ObjC 元数据 + chained fixups + 选择子 trampoline，脚本在 `tools/sjj_re/`。
2. **兜底**：宿主每次更新都可能改名。所有 hook 都要能“找不到就跳过”，
   绝不能因为一个类消失就崩掉整个 App。

代码本身通常只有几百行。
