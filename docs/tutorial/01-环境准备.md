# 01 环境准备

目标：让一行 `NSLog` 出现在抖音进程的日志里。这一步通了，后面全是写逻辑。

## 1. 设备与系统

| 方案 | 适用 | 说明 |
| --- | --- | --- |
| 越狱（Dopamine / palera1n） | iOS 15–16.x | 能装 `mobilesubstrate`，最省事，`make install` 直接生效 |
| TrollStore + TrollFools | iOS 14–17.x 部分版本 | 不需要越狱，把 dylib 注入进 App 的签名包里 |
| 巨魔签（轻松签 / ESign） | 同上 | 图形界面注入，适合不碰命令行的场景 |

判定自己走哪条：能 `ssh root@设备IP` 就是越狱方案；只能装 ipa 就是 TrollStore 方案。

## 2. 电脑侧工具链

```bash
# 1) Xcode 命令行工具（clang、ldid 依赖）
xcode-select --install
brew install ldid dpkg

# 2) Theos
export THEOS=/opt/theos
sudo git clone --recursive https://github.com/theos/theos.git $THEOS
sudo chown -R $(id -u):$(id -g) $THEOS

# 3) SDK：直接软链 Xcode 自带的，不必另外下载
mkdir -p $THEOS/sdks
ln -sfn "$(xcrun --sdk iphoneos --show-sdk-path)" "$THEOS/sdks/iPhoneOS18.5.sdk"
```

把这四行写进 `~/.zshrc`：

```bash
export THEOS=/opt/theos
export PATH=$THEOS/bin:$PATH
export THEOS_DEVICE_IP=<设备IP>
export THEOS_DEVICE_PORT=22
```

## 3. 建一个空工程

```bash
$THEOS/bin/nic.pl     # 选 iphone/tweak
```

依次填：项目名 `hello`、包名 `com.you.hello`、作者、**过滤的 Bundle ID**。
抖音的 Bundle ID 是 `com.ss.iphone.ugc.Aweme`（用 `frida-ps -Ua` 或 Filza 里的 Info.plist 确认）。

生成的目录：

```
hello/
├── Makefile
├── Tweak.xm
├── control
└── hello.plist      # 注入过滤
```

## 4. 两行代码验证注入

`Tweak.xm`：

```objc
%ctor {
    NSLog(@"[hello] injected into %@", [[NSBundle mainBundle] bundleIdentifier]);
}
```

`make package install`（越狱设备）或 `make package` 后用 TrollFools 注入。

看日志：

```bash
# 越狱设备
ssh root@<设备IP> "tail -f /var/log/syslog | grep hello"

# 任意设备（需要 libimobiledevice）
brew install libimobiledevice
idevicesyslog | grep hello
```

看到 `[hello] injected into com.ss.iphone.ugc.Aweme` 就算通了。

## 5. 常见失败

| 现象 | 原因 |
| --- | --- |
| 完全没日志 | plist 里的 Bundle ID 写错；或 dylib 没被签名（TrollFools 之外要 `ldid -S`） |
| App 启动就崩 | tweak 在 `%ctor` 里访问了尚未初始化的类，或链接了 App 没有的框架 |
| 只有越狱设备有日志 | TrollStore 方案下 dylib 注入的是签名后的 ipa，重装会被覆盖 |
| `make install` 卡住 | 设备没开 SSH，或 `THEOS_DEVICE_IP` 没导出 |
