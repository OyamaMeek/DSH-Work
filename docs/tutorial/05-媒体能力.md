# 05 媒体能力

插件里最容易做出差异化的部分：下载、去水印、合并音轨、转码、LivePhoto 保存。

## 1. 拿到资源地址

抖音的视频通常有两个地址：带水印的播放地址和 `playwm` 换成 `play` 的地址。
拉流信息在 `AWEAwemeModel`（或 `AWEVideoModel`）里：

```objc
%hook AWEAwemeModel
- (NSString *)videoURL {
    NSString *url = %orig;
    return [url stringByReplacingOccurrencesOfString:@"playwm" withString:@"play"];
}
%end
```

具体字段名随版本变化，第 2 篇的方法（枚举实例变量 + KVC）在这里最有用。

## 2. 下载：NSURLSession

```objc
NSURLSessionDownloadTask *task = [[NSURLSession sharedSession]
    downloadTaskWithURL:url completionHandler:^(NSURL *location, NSURLResponse *resp, NSError *err) {
        NSURL *dst = [NSURL fileURLWithPath:[NSTemporaryDirectory() stringByAppendingPathComponent:@"v.mp4"]];
        [[NSFileManager defaultManager] moveItemAtURL:location toURL:dst error:nil];
    }];
[task resume];
```

要进度条就用 delegate，不要在 completionHandler 里轮询。
本项目的 `SJJMediaManager` 用四个字典把「任务 / 回调 / 文件路径 / 文件名」串起来，
核心是给每个下载分配一个 downloadID，完成后按 ID 取回调再释放。

## 3. 合并音视频

抖音的部分视频音轨是分开的。合并要用 `AVMutableComposition`：

```objc
AVMutableComposition *comp = [AVMutableComposition composition];
AVMutableCompositionTrack *v = [comp addMutableTrackWithMediaType:AVMediaTypeVideo
                                                  preferredTrackID:kCMPersistentTrackID_Invalid];
AVMutableCompositionTrack *a = [comp addMutableTrackWithMediaType:AVMediaTypeAudio
                                                  preferredTrackID:kCMPersistentTrackID_Invalid];
[v insertTimeRange:CMTimeRangeMake(kCMTimeZero, videoAsset.duration)
           ofTrack:[videoAsset tracksWithMediaType:AVMediaTypeVideo].firstObject
            atTime:kCMTimeZero error:nil];
[a insertTimeRange:CMTimeRangeMake(kCMTimeZero, audioAsset.duration)
           ofTrack:[audioAsset tracksWithMediaType:AVMediaTypeAudio].firstObject
            atTime:kCMTimeZero error:nil];
```

**坑**：不要每段音频都 `addMutableTrack`，否则成片会有几十条音轨，播放器和相册都会出问题。
一条音轨上多次 `insertTimeRange` 才对。

## 4. 转码

```objc
AVAssetExportSession *exporter =
    [[AVAssetExportSession alloc] initWithAsset:asset presetName:AVAssetExportPresetHighestQuality];
exporter.outputURL = outURL;
exporter.outputFileType = AVFileTypeMPEG4;
exporter.shouldOptimizeForNetworkUse = YES;
[exporter exportAsynchronouslyWithCompletionHandler:^{
    if (exporter.status == AVAssetExportSessionStatusCompleted) { /* 完成 */ }
}];
```

预设选择：`Passthrough` 最快但不重编码；`HighestQuality` 兼容性最好但慢；
`MediumQuality` 适合分享。

## 5. LivePhoto

LivePhoto 是「一张 HEIC + 一段 MOV」，两者靠 metadata 里的 content identifier 关联：

```objc
AVMutableMetadataItem *item = [[AVMutableMetadataItem alloc] init];
item.key = (id)CFBridgingRelease(CMMetadataKeyCreateContentIdentifier());
item.keySpace = AVMetadataKeySpaceQuickTimeMetadata;
item.value = identifier;
item.dataType = @"com.apple.metadata.datatype.UTF-8";
```

两张图/两段视频都要写入**同一个** identifier，系统相册才会配对。
本项目的关键常量：`mdta/com.apple.quicktime.still-image-time`。

## 6. 保存到相册

```objc
[PHPhotoLibrary requestAuthorization:^(PHAuthorizationStatus status) {
    [[PHPhotoLibrary sharedPhotoLibrary] performChanges:^{
        PHAssetCollectionChangeRequest *album =
            [PHAssetCollectionChangeRequest creationRequestForAssetCollectionWithTitle:@"抖音"];
        PHAssetCreationRequest *req = [PHAssetCreationRequest creationRequestForAsset];
        [req addResourceWithType:PHAssetResourceTypePhoto fileURL:imageURL options:nil];
        [album addAssets:@[req.placeholderForCreatedAsset]];
    } completionHandler:^(BOOL ok, NSError *err) { }];
}];
```

iOS 14+ 记得在 Info.plist 加 `NSPhotoLibraryAddUsageDescription`，
注入式插件没法改宿主 Info.plist，所以要靠宿主已有的权限，或走 `PHPhotoLibrary` 的受限写入。

## 7. 命名与临时文件

- 临时文件放 `NSTemporaryDirectory()`，退出时清掉。
- 成片命名带时间戳和 awemeID，避免覆盖：`sjj_%@_%lld.mp4`。
- 转码是重活，放独立串行队列（本项目用 `sjj.transcode.queue`），别占主线程。
